FAQ

What are the best Cursor rules for Godot 4?

Use a glob-scoped rule (globs: project.godot, **/*.gd) that tells the agent to use Godot 4 syntax only (@export, @onready, await, signal.connect, CharacterBody2D), static typing, and 'call down, signal up'. The free Agent Rules Starter includes a ready-made godot4-gdscript.mdc with a Godot 3 → 4 table.

How do I stop Cursor writing Godot 3 code?

Add a Cursor rule in .cursor/rules/ that lists Godot 3 patterns and their Godot 4 replacements, e.g. yield → await, export var → @export var, KinematicBody2D → CharacterBody2D, instance() → instantiate(). Agents follow explicit old → new tables much more reliably than general advice.

Is there an AGENTS.md template for Next.js and Supabase?

Yes. The free pack has a general AGENTS.md template, and the Starter Pack includes a pre-filled AGENTS.md for Next.js App Router + Supabase with real commands for dev, typecheck, lint, tests, migrations and type generation.

What's the difference between .cursorrules, .cursor/rules and AGENTS.md?

The legacy .cursorrules is a single file at the project root. Current Cursor uses .cursor/rules/*.mdc files with description, globs and alwaysApply frontmatter, so rules can be scoped to file types. AGENTS.md is a plain markdown file read by Cursor, Codex, Copilot and many other agents.

Do these rules work with Claude Code?

Yes. Claude Code reads CLAUDE.md. Both packs include a CLAUDE.md template, and you can put @AGENTS.md in it to share one set of instructions with Cursor and other agents.

How do I stop Cursor using deprecated Supabase auth helpers?

Add a rule saying to use @supabase/ssr (createServerClient / createBrowserClient), never @supabase/auth-helpers-nextjs, and to check auth on the server with supabase.auth.getUser(). That's in the free nextjs-supabase.mdc rule.

Are there Cursor rules for Unity 6 and Unreal Engine 5?

Yes, in the US$19 Starter Pack. The Unity 6 rule covers API renames like Rigidbody.velocity → linearVelocity and the Input System; the Unreal rule covers UPROPERTY/TObjectPtr, Enhanced Input and replication.
