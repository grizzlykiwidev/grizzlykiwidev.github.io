Godot 4 AI agent rules for Cursor and Claude Code

AI coding agents learned GDScript mostly from Godot 3 code, so they keep writing yield, export var and KinematicBody2D in Godot 4 projects. Three small files fix most of it: a Cursor rule, AGENTS.md and CLAUDE.md. This page explains each one and gives you a free Godot 4 rule to copy.

1. Cursor rules (.cursor/rules/*.mdc)

Cursor loads project rules from .cursor/rules/. Each .mdc file starts with frontmatter that decides when it applies. For Godot, scope the rule with globs so it loads whenever the agent touches GDScript or scenes, and keep it short and concrete. Agents follow an explicit "Godot 3 (wrong) → Godot 4 (use)" table much better than general advice. Legacy .cursorrules files are deprecated; move them into .cursor/rules/.

Here is the core of the free rule. Save it as .cursor/rules/godot4-gdscript.mdc (the full version is on GitHub):

---
description: Godot 4.x GDScript conventions; prevents Godot 3 syntax
globs: project.godot, **/*.gd, **/*.tscn
alwaysApply: false
---

# Godot 4 GDScript

## Godot 4 syntax only (agents often emit Godot 3)
| Godot 3 (wrong) | Godot 4 (use) |
|---|---|
| `export var speed = 200` | `@export var speed := 200.0` |
| `onready var x = $X` | `@onready var x: Node2D = $X` |
| `yield(get_tree().create_timer(1), "timeout")` | `await get_tree().create_timer(1.0).timeout` |
| `connect("pressed", self, "_on_pressed")` | `pressed.connect(_on_pressed)` |
| `emit_signal("died")` | `died.emit()` |
| `KinematicBody2D` / `Spatial` | `CharacterBody2D` / `Node3D` |
| `move_and_slide(velocity, Vector2.UP)` | set `velocity`, then `move_and_slide()` |
| `tool` | `@tool` |
| `instance()` | `instantiate()` |

## Style
- Static typing everywhere: `var hp: int = 100`, `func take_damage(amount: int) -> void:`.
- snake_case for files, funcs, vars; PascalCase for `class_name` and nodes.
- Declare signals with typed args: `signal health_changed(new_value: int)`.

## Architecture
- "Call down, signal up": parents call children's methods; children emit signals.
- Use `%UniqueName` nodes or `@export` node references instead of fragile `$A/B/C` paths.
- Physics movement in `_physics_process(delta)`; use Input Map actions, not raw keycodes.
- Data in `Resource` subclasses instead of dictionaries.
- Don't edit `.tscn`/`.tres` by hand beyond trivial changes.

2. AGENTS.md: instructions for every agent

AGENTS.md is a plain Markdown file in the project root, read by Codex, Cursor, Copilot, Windsurf and other agents. For a Godot 4 project it should say:

  • the exact Godot version (e.g. 4.7) and that only Godot 4 syntax is allowed;
  • the folder layout (scenes/, scripts/, resources/) and where new content goes;
  • conventions: static typing, "call down, signal up", data in Resource files, Input Map actions instead of raw keys;
  • how to check work: a headless run such as godot --headless --path . --quit or your test script;
  • what not to do: hand-editing .tscn files beyond trivial changes, renaming autoloads, changing project.godot without asking.

3. CLAUDE.md: for Claude Code

Claude Code reads CLAUDE.md automatically at the start of every session. To stop two sets of instructions drifting apart, keep the real rules in AGENTS.md and make CLAUDE.md a short file that points to it and adds anything Claude-specific, such as which commands it may run without asking.

Quick setup checklist

  1. Add .cursor/rules/godot4-gdscript.mdc (above).
  2. Add AGENTS.md with your Godot version, layout, conventions and check command.
  3. Add a short CLAUDE.md that points to AGENTS.md.
  4. Ask the agent to run the headless check after every change and fix any errors it prints.

FAQ

What are the best Cursor rules for Godot 4?

A glob-scoped .mdc rule in .cursor/rules/ (globs: project.godot, **/*.gd, **/*.tscn) that forces Godot 4 syntax (@export, @onready, await, signal.connect(), CharacterBody2D), static typing and "call down, signal up". The free rule on this page does exactly that and includes a Godot 3 to 4 table.

What is AGENTS.md in a Godot project?

AGENTS.md is a plain Markdown file in the project root that tells AI coding agents (Codex, Cursor, Copilot, Windsurf and others) how the project is built: the Godot version, folder layout, coding conventions, how to run checks and what not to touch.

What is CLAUDE.md and do I need it as well as AGENTS.md?

CLAUDE.md is the file Claude Code loads automatically at the start of a session. Keep the real instructions in AGENTS.md and make CLAUDE.md short, pointing to AGENTS.md and adding anything Claude-specific, so the two never drift apart.

How do I stop AI agents writing Godot 3 code?

Give the agent an explicit old to new table: yield to await, export var to @export var, KinematicBody2D to CharacterBody2D, instance() to instantiate(), string-based connect() to signal.connect(). Agents follow concrete replacement tables far more reliably than general advice. Then have the agent run a headless check so mistakes show up as errors.

How can an agent check GDScript without opening the editor?

Run Godot headless, for example godot --headless --path . --quit to load the project and print parse errors, or your project's own test scene. Tell the agent in AGENTS.md to run it after every change.
